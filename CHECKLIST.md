# Ручная проверка на Windows (то, что автотесты не покрывают)

Перед выпуском пройдите по пунктам на настоящей Windows (лучше на двух ПК).

**Запуск и вид**
- [ ] `CloudSaveManager.exe` стартует без консоли; значок в трее и в окне чёрно-зелёный.
- [ ] Масштаб экрана 100 / 125 / 150 %: ничего не обрезается, обложка и иконки чёткие.
- [ ] Шрифт Shutters лежит в `assets/fonts/` (внутри .exe: `assets\fonts`); кириллица в заголовках читается.

**Облака (реальные аккаунты)**
- [ ] GitHub, GitLab, WebDAV, Dropbox: «Проверить подключение», выгрузка, загрузка, удаление аккаунта.
- [ ] Dropbox: авторизация по коду, перезапуск программы через >4 часа (обновление токена).
- [ ] Файл сохранения >1 МБ на GitHub/GitLab (лимиты API).

**Игры и процессы**
- [ ] Игра с античитом (EAC/BattlEye): процесс определяется, выход фиксируется, выгрузка после закрытия.
- [ ] Кнопка «Играть»: .exe, ярлык .lnk и `steam://rungameid/…`; при более новом облаке сохранение скачивается ДО запуска.
- [ ] Игра запущена из лаунчера (Steam/Epic): перезапуск лаунчера не вызывает ложную выгрузку.

**Два компьютера**
- [ ] ПК 1: добавить игру → ПК 2: добавить тот же аккаунт → игра и сохранение появились сами; пути подставлены под другое имя пользователя.
- [ ] Игра с путём вне профиля (`D:\Games\…`): слот остался пустым, путь указывается вручную.
- [ ] Конфликт (играли на обоих ПК без синхронизации): открывается окно сравнения, ничего не теряется, копия заменяемой версии есть в резервных копиях.

**Надёжность**
- [ ] Отключить сеть на момент закрытия игры → автоповтор; включить сеть → выгрузка прошла.
- [ ] «Отмена» в окне выгрузки/загрузки на большом файле: локальные файлы не тронуты.
- [ ] Слот-папка с масками `*.log, cache`: исключённые файлы не уходят в облако и не пропадают при загрузке.
- [ ] Автозапуск с Windows (`--minimized`), выход через трей завершает процесс.
